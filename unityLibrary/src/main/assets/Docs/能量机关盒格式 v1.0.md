# 星轨机关关卡格式 v2.0（应用 0.9.2）

关卡资源是 `Assets/Resources/EnergyBoxes.json`，当前顶层 `version=3`，`levels` 包含24关。解析器兼容version=1的六关和version=2的十二关。运行包不再包含旧星环、自由连线和旧沙盒。

## 基本字段与单位

关卡：`id`唯一，`title`标题，`lesson`推理目标，`turns/splitters`转向件与分流件库存，`nodes`节点，`hints`三条渐进提示，`reference`验证解，`links`联动组，`tutorial/tutorialNode/tutorialSocket`教学定义，`syncWindow`同步容差。省略可选数组时默认空数组。

节点：`id/title/kind`，kind为source/goal/socket/relay/blocked；`x/y/z`为机关局部米制坐标，正z远离正面观察者；x在±0.9m，y/z在±0.5m。最多18节点。`units`为能源或目标格数，取1..4；一个能源，至少一个目标，供需总量守恒。

固定source/relay的`outputs`恰好一个目标ID；goal/blocked/socket没有固定出口。socket使用`choices`；每项含`kind=turn/split`、`name`、`outputs`、可选`parts`与`delay`。转向出口一个，分流两个不同出口，不允许缺失引用或自指。

状态数组按nodes中socket出现顺序排列。0未安装，1..N为该插槽choices中的配置。reference是自动验证用答案，运行界面不展示。安装、更换、取回必须满足库存；更换返还旧件。保留在未通电支路的元件也占库存。撤销最多20步。

## 能量与印记

转向保持格数。parts为空的分流件精确二等分，奇数能量不能等分，不向下取整；parts如[3,1]按outputs顺序分配，两数之和必须等于到达格数。每个接点仅能被一个分支访问；合流、循环、断口、空插槽、泄漏、能量或印记错误都不能通关。投影交叉不是接点，实际按固定导轨拓扑求解，没有自由拉线或碰撞避障。

relay的`rune`追加月/星/日；goal的`code`检查完整符文串，最多三个符文，空串表示不检查。分流复制已有印记。relay的`gate`检查完整印记；`swapFrom/swapTo`仅替换符合条件的末印；`operation=reverse`反转整串，`operation=erase`删除末印，空白退印会阻断。这些效果不能在同一节点混用。

## 联动与节拍

links中的`a/b`引用两个独立socket，`map`是包含0的完整排列且map[0]=0，配置元件类型须对应；反向操作用逆映射。一次操作同时检查两件库存，原子提交，一步撤销恢复两处。

syncWindow=0为普通关卡，演示时长按导轨长度确定，每段最少0.55秒。syncWindow>0为节拍关，每段固定1拍（84 BPM，每拍60/84秒），choices.delay为0..4拍的节点等待。等待发生在向外传播之前。所有目标必须正确接收且到达时间差≤syncWindow；当前节拍关容差0.1拍。等待阀显示剩余拍数。

显式点击测试后才模拟。暂停、逐段、停止只控制观察，不改变解。完整播放且全部条件满足才记录通关；未播放的诊断不会提前显示。

## 关卡与教学编写

`Tools/author_energy_boxes.py`确定性生成24关。四个星域各六关：能量与印记、条件与联动、分配与倒序、退印与节拍。新规则在第13/16/19/22关实际操作教学；既有操作、等分、锁印、条件门、换印、联动教学保留。tutorial取gate/swap/link/prism/reverse/erase/sync或空串。教学先读取指定机关，再实际装件、验证，不能仅靠等待推进。

新增关卡先确定推理矛盾、干扰路线和库存，再运行EnergyBoxSolver.Solutions穷举。枚举上限200000。reference必须真实通关；每种新规则需测试反例、唯一解和交互可达。唯一解不代表有趣或难度足够，还需真人试玩。

核心代码：Gameplay/EnergyBoxSession.cs、Gameplay/BoxTutorial.cs；展示Rendering/EnergyBoxView.cs；UI为UI/OrbitalLoomBoxUI.cs。扩展规则需同时更新字段校验、求解、线索、教学、渲染与测试。Editor负责导出原生网格，运行时复用对象池。

项目自有格式与示例允许自由修改与分享；第三方SDK遵循其各自许可。当前版本不提供沙盒编辑或文件导入导出入口。

## 0.9.2 组合挑战与声音

第15/18/23/24关重写，沿用ID以保留通关记录。对应共享通道让位、加工发生在分流之前、三路联动等待、路由/印记/等待组合。联动映射全部展示于目标→联动表；同出口反向延时组会直接提示等待和，提供必要推理线索。

Audio/LoomScore将真实求解结果的拍数编成音频事件，DSP时间驱动84BPM视觉和声音。Resources/LoomAudio内为原创导入PCM素材，Tools/create_loom_score.py可重生成。节拍音乐音量独立存于settings-v1.json的rhythmVolume，默认0.65，静音不影响求解。暂停/停止/菜单取消预排，不补播错过事件。新规则仍由第22关教学，强调可看拍数、无需踩点。

## 0.9.3 可选空间线索

关卡可带`relic`对象，字段为`kind`（parallax/mirror/resonance）、`title`、`instruction`、`discovery`、`angle`（-180..180度）。旧关卡省略该对象；Unity JsonUtility往返时产生的全空对象视为省略。未知种类或非有限角度拒绝加载。

三个Editor预建样板对应第15/18/23关。观察独立转动、记录证据，不修改关卡图或求解结果；等价文字入口不耗提示，不用通过强制视角任务才能测试。重做布局保留本次已发现线索。正式扩展其他种类时须同时提供Editor几何、阅读线索、教学和验证，不能只新增JSON种类名。
