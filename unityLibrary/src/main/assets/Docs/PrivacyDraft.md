# Orbital Loom 隐私说明草稿 · 0.9.2

应用自编功能不提供账号、内购、广告、聊天或后端。关卡资源内置，进度energy-box-v2.json与设置settings-v1.json保存在应用私有目录。设置包含教学完成记录；通关进度沿用旧版本。旧模式不再提供入口，升级不会主动擦除旧存档。

应用通过PICO官方空间输入事件接收当前目标与位置，用于操作。不由应用自编逻辑记录或上传相机、环境扫描、原始眼动或手部骨骼。当前交付以手柄射线与扳机验证，不把SDK能力等同于应用已完成的功能。

清除应用数据或卸载按系统策略删除本地记录，当前无云同步。PICO/Unity及依赖可能包含平台诊断或遥测，需在发行前审计最终清单、权限、网络行为和SDK隐私文档。当前开发测试包不能据此声称“无数据采集”。

发行者需补全主体、联系方式、生效日期、SDK清单与实际数据行为，完成审核后发布正式隐私政策。
